# HR-Analytics-project

This project analyzes employee attrition using Python (Pandas, Matplotlib), SQL, Excel, and Power BI to uncover key business insights.

---

## Tools Used
- Python (Pandas, Matplotlib)
- SQL (SQLite)
- Excel
- Power BI

---

## Project Structure
- data/ → raw dataset
- scripts/ → Python and SQL analysis
- dashboard/ → Power BI dashboard
- excel/ → Excel analysis

---

## Key Insights
- Employees who left had lower average salary (~33K) compared to those who stayed (~60K)
- Low job satisfaction is strongly linked to higher attrition
- Sales department has the highest attrition rate
- Finance department has zero attrition and highest salaries

---

## Dashboard Features
- Total Employees KPI
- Attrition Rate
- Average Salary
- Attrition by Department
- Salary Band Analysis
- Job Satisfaction Impact
- Interactive Filters

---

## Conclusion
This project demonstrates how data analysis can help identify factors behind employee attrition and support better HR decision-making.
